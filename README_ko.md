# 먹보 모쿠모쿠

브라우저에서 바로 플레이할 수 있는 액션 게임입니다. 점을 먹으며 무작위로 생성되는 미로를 진행하세요.
외부 라이브러리나 서버가 필요하지 않습니다.

## 실행 방법

웹 브라우저에서 `index.html`을 열면 됩니다.
스마트폰에서는 세로 화면 플레이를 권장합니다.

## 스크린샷

### 타이틀 화면

현재 최고 점수와 최고 스테이지를 보여 주며, 쉬움, 보통, 어려움 난이도를 선택할 수 있습니다.

![타이틀 화면](assets/screenshots/title-screen.png)

### 게임 화면

게임 화면에는 점수, 스테이지, 남은 목숨, 미로, 점, 유령, 아이템, 화면 조작 버튼이 표시됩니다.
오른쪽 상단 버튼으로 일시정지, 소리, 언어, 십자 버튼 위치, 설정을 조작할 수 있습니다.

![게임 화면](assets/screenshots/gameplay-overview.png)

## 게임 방법

타이틀 화면에서 쉬움, 보통, 어려움 중 하나를 선택합니다.
미로 안의 점을 모두 먹으면 스테이지가 클리어됩니다.
유령에 닿으면 목숨을 하나 잃습니다. 파워 점을 먹으면 일정 시간 동안 유령을 쓰러뜨릴 수 있습니다.
스테이지 2부터는 이동 속도 증가, 보호막, 유령 퇴치 효과가 있는 아이템이 나타날 수 있습니다.
일정 조건을 만족하면 과일이 나타나며, 먹으면 보너스 점수를 얻습니다.

## 조작 방법

- 키보드: 방향키 또는 W/A/S/D
- 스마트폰: 화면의 십자 버튼 또는 화면 스와이프
- 일시정지: `P` 키, `Esc` 키, 또는 화면 상단의 일시정지 버튼
- 상단 버튼: 소리 켜기/끄기, 언어 변경, 십자 버튼 위치 변경, 설정 열기

## 설정 및 저장 데이터

BGM 음량, 효과음 음량, 진동을 설정할 수 있습니다.
최고 점수와 설정은 브라우저의 `localStorage`에 저장됩니다.
브라우저 사이트 데이터를 삭제하면 이 기록도 초기화됩니다.

## 지원 언어

일본어, 영어, 중국어, 한국어, 스페인어를 지원합니다.
언어 버튼을 누르면 순서대로 전환됩니다.
