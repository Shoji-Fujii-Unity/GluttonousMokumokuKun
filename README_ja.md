# 食いしん坊モクモクくん

ブラウザで遊べる、ドットを食べて迷路を進むアクションゲームです。
外部ライブラリやサーバーは必要ありません。

## 起動方法

`index.html` をブラウザで開いてください。
スマートフォンでは縦画面でのプレイを推奨します。

## スクリーンショット

### タイトル画面

現在のハイスコアと到達ステージを表示し、「かんたん」「ふつう」「むずかしい」から難易度を選択できます。

![タイトル画面](assets/screenshots/title-screen.png)

### ゲーム画面

スコア、ステージ、残りライフ、迷路、ドット、ゴースト、アイテム、画面上の操作ボタンを表示します。
画面右上のボタンから、ポーズ、音声、言語、十字キーの位置、設定を操作できます。

![ゲーム画面](assets/screenshots/gameplay-overview.png)

## 遊び方

タイトル画面で「かんたん」「ふつう」「むずかしい」から難易度を選びます。
迷路内のドットをすべて食べるとステージクリアです。
ゴーストに触れるとライフを失います。パワードットを食べると、一定時間ゴーストを倒せます。
ステージ2以降には、速度アップ、シールド、ゴーストを遠ざけるアイテムが出現します。
条件を満たすとフルーツが出現し、食べるとボーナス点を獲得できます。

## 操作方法

- キーボード: 矢印キー または W/A/S/D
- スマートフォン: 画面の十字キー、または画面上のスワイプ
- ポーズ: `P` キー、`Esc` キー、または画面上部の一時停止ボタン
- 画面上部のボタン: 音声オン/オフ、言語変更、十字キーの位置変更、設定

## 設定と保存

BGM音量、効果音音量、バイブレーションを設定できます。
ハイスコアと設定はブラウザの `localStorage` に保存されます。
ブラウザの保存データを削除すると、これらの記録もリセットされます。

## 対応言語

日本語、英語、中国語、韓国語、スペイン語に対応しています。
言語ボタンを押すと順番に切り替わります。
