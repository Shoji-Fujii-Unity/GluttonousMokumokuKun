# 贪吃的小莫莫

这是一款可以直接在浏览器中游玩的动作游戏。玩家需要吃掉豆子，在随机生成的迷宫中前进。
不需要外部库或服务器。

## 启动方法

使用浏览器打开 `index.html` 即可。
在手机上建议使用竖屏游玩。

## 游戏截图

### 标题画面

标题画面显示当前最高分和最高关卡，并提供简单、普通和困难三个难度选项。

![标题画面](assets/screenshots/title-screen.png)

### 游戏画面

游戏画面显示分数、关卡、剩余生命、迷宫、豆子、幽灵、道具和屏幕操作按钮。
右上角的按钮可用于暂停、声音、语言、十字键位置和设置。

![游戏画面](assets/screenshots/gameplay-overview.png)

## 游戏玩法

在标题画面选择简单、普通或困难难度。
吃掉迷宫中的所有豆子即可通过关卡。
碰到幽灵会失去一条生命。吃下能量豆后，可以在限定时间内消灭幽灵。
从第2关开始，迷宫中可能出现加速、护盾和驱赶幽灵的道具。
满足一定条件后会出现水果，吃掉水果可以获得额外分数。

## 操作方法

- 键盘：方向键或 W/A/S/D
- 手机：屏幕上的十字键，或在画面上滑动
- 暂停：按 `P`、`Esc`，或点击画面顶部的暂停按钮
- 顶部按钮：切换声音、切换语言、移动十字键位置、打开设置

## 设置与保存数据

可以调整背景音乐音量、音效音量和震动功能。
最高分和设置会保存在浏览器的 `localStorage` 中。
清除浏览器的网站数据后，这些记录也会被重置。

## 支持的语言

支持日语、英语、中文、韩语和西班牙语。
点击语言按钮即可依次切换。
